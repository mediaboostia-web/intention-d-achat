# Blog (lot 13d) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A public, SEO-ready blog with categories and a guide-for-a-contact call to action, fully managed (CRUD) from the support-admin with a visual editor.

**Architecture:** Tiptap JSON stored on `BlogPost.content`; a pure whitelist renderer (`lib/tamani/blog-render.ts`) turns it into HTML + a table of contents for the public pages. Server queries in `lib/server/tamani/blog.ts`; admin routes under `/api/admin/blog/*` (ADMIN reads, SUPERADMIN writes, `logAdminAction`); one public route `/api/public/blog-leads`. Public pages are server components revalidated on every admin write.

**Tech Stack:** Next.js 16, Prisma 5, zod 4, Tiptap 3.33.0 (admin only), Vitest.

**Spec:** [docs/superpowers/specs/2026-11-21-blog-design.md](../specs/2026-11-21-blog-design.md)

## Global Constraints

- Routes: `runtime = 'nodejs'`, `withRequestContext`, `verifyCsrf` on admin writes, `gatedAdmin('ADMIN')` to read, `gatedSuperadmin()` to write, `enforceAdminRateLimit`, every write through `logAdminAction` in the same transaction.
- Public route: no CSRF, `enforcePublicRateLimit`, honeypot `website`, number normalized by `normalizePhone`, never logged.
- Migration `9m_blog` is written, not applied, until the porteur says OK.
- No « FCFA » literal, no default Tailwind palette, Skeletons not « Chargement… », no `motion` in public pages that do not need it.
- Tiptap packages pinned to `3.33.0` and imported only from `components/admin/blog/*`.

## Review Focus

1. A stored document with `javascript:` links, `<script>` text or unknown node types renders as harmless text / is dropped.
2. Two articles with the same slug → 409 `BLOG_SLUG_TAKEN`, not a 500.
3. A draft is a 404 publicly, including through its slug and the sitemap.
4. Deleting the default guide or a category in use leaves no article pointing at nothing.
5. The lead form with a wrong number → 400 `INVALID_PHONE`; with no guide configured the button is hidden.
