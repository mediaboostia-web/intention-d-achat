# Images de la page d'accueil

Range ici les images faites avec ChatGPT, sous ces noms exacts :

`hero.png`, `video-affiche.png`, `probleme.png`, `etape-1.png`, `etape-2.png`, `etape-3.png`, `avant.png`, `apres.png`, `communaute.png`

Lance ensuite `pnpm landing:images` à la racine du projet. Il écrit les versions WebP légères dans `frontend/public/accueil/`. Ce sont elles que le site et la maquette [2026-10-25-page-accueil-v3.html](../2026-10-25-page-accueil-v3.html) affichent.

Les PNG restent sur ton ordinateur : git les ignore. Les prompts sont dans [prompts-images-accueil.md](../../prompts-images-accueil.md).
